**规划中 · 第 04 节大纲**

拟用设备接入、订单管理与报表三类模块，比较它们放在一个应用、独立进程或独立服务时的后果。

| 类型 | 拟比较的问题 |
| --- | --- |
| 单体 | 一个交付单元如何保持开发、发布和调试简单？ |
| 模块化单体 | 同一部署内如何约束模块依赖，并明确数据职责？ |
| SDK | 如何把调用接口、类型和工具交付给其他开发者？ |
| 插件 | 宿主如何发现、加载和更新扩展，如何处理版本不兼容？ |
| 微服务 | 独立交付或扩容是否值得引入网络、数据一致性和运维成本？ |

SDK 和插件是可用于多种架构的集成方式。拟参考 [Spring Modulith 文档](https://docs.spring.io/spring-modulith/reference/) 和 [GitHub](https://github.com/spring-projects/spring-modulith)。
